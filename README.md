# REMEDIUM CINEMA — исправление видео у гостя

## Запуск

Нужен Node.js 18 или новее (рекомендуется актуальная LTS-версия).

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Порт можно изменить переменной окружения PORT.
Создатель входит первым, выбирает фильм и отправляет гостю ссылку кнопкой
«Пригласить». На другом устройстве нужен доступный адрес сервера, а не localhost.
На хостинге используйте HTTPS и поддержку WebSocket/Socket.IO.

Для обновления замените index.html, server.js, package.json и package-lock.json,
выполните npm ci и перезапустите сервер. Существующий cinema-data.json сохраните:
в нём комнаты и переписка. В архиве пользовательских данных нет.
После обновления обновите страницу на обоих устройствах.

## Что исправлено

- Если браузер запрещает запуск со звуком, обычное видео пробует запуститься
  без звука. Кнопка на экране позволяет разрешить просмотр со звуком.
- YouTube сообщает о блокировке автозапуска через такую же кнопку.
  Для VK доступна кнопка запуска и штатные элементы управления плеера.
- Гость больше не отправляет паузу своего плеера в общую комнату.
  Сервер принимает обычные команды синхронизации только от создателя.
  Совместный запуск после готовности обоих участников сохранён.
- Ссылки VK сохраняют параметр hash для видео, доступных по ссылке.
  Сохранённые комнаты также восстанавливают его из исходной ссылки.
- VK API подключается после загрузки iframe и повторно запрашивает
  состояние комнаты после инициализации плеера.
- Повторный выбор того же фильма сбрасывает плеер у обоих участников.

Если браузер показывает кнопку «Нажми для просмотра со звуком», нажмите её.
Можно также нажать Play внутри встроенного плеера. Пауза гостя остаётся
локальной; общий просмотр управляется создателем.

Ролик должен разрешать встраивание и быть доступен на устройстве гостя.
Для закрытых VK-видео используйте полную ссылку «Код для встраивания» с hash.
Авторизацию, региональные ограничения и запреты встраивания самих сервисов
приложение не обходит. Прямая MP4/WebM-ссылка должна вести на видеофайл.

## Проверки

Проверены в двух изолированных сессиях Chromium: вход гостя во время просмотра,
блокировка автозапуска, включение звука нажатием, защита общего состояния от
команд гостя, пауза/перемотка/продолжение ведущего, переподключение, повторный
выбор фильма и передача hash в VK iframe. Внешнее воспроизведение конкретных
роликов VK и YouTube не проверено.

Проверка синтаксиса сервера: npm run check.
Регрессионный тест: tests/guest-video.mjs. Инструкции по его запуску в файле.
