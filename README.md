# REMEDIUM CINEMA — исправленный плеер

## Запуск

Нужен Node.js 18 или новее.

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Для хостинга используйте команду запуска `npm start`; порт задаётся переменной `PORT` (по умолчанию 3000).

Загрузите на сервер **все файлы проекта**, а не только index.html. Это приложение с Node.js и Socket.IO; GitHub Pages без отдельного сервера его не запускает. Файл package-lock.json закрепляет зависимости.

## Что исправлено

- Для VK включён JavaScript API, исправлены подписки на события, ожидание готовности, управление воспроизведением, звуком и перемоткой.
- Play, пауза, перемотка ±10 секунд, звук и полный экран оформлены одинаковыми SVG-кнопками с подсказками.
- Убраны дублирующие кнопки «Режим кино» и «Выйти». Полный экран включается одной кнопкой справа в плеере; F также переключает режим.
- В полном экране видео занимает всю область, кнопки находятся поверх и скрываются при просмотре. Наведите указатель или коснитесь нижнего края для возврата панели. Выход — кнопкой или Escape.
- Для браузеров без Fullscreen API предусмотрено разворачивание на всё окно.
- Исправлены нулевая позиция, границы перемотки и переключение Play/Pause при задержках API. Сохранены комнаты, чат, роли и личный список фильмов.
- При запрете автозапуска появляется кнопка запуска со звуком, в том числе у гостя.

Пропорции исходного видео сохраняются: чёрные поля у фильма другого формата допустимы, изображение не обрезается и не растягивается.

## Перенос существующего сайта

Замените файлы приложения и перезапустите Node.js. Сохраните свой `cinema-data.json`: в нём комнаты и сообщения. Архив с исправлениями не содержит чужих комнат и не заменяет этот файл. Список фильмов хранится в браузере; для его переноса используйте кнопку «Копия».

## Ограничения видеосервисов

VK/YouTube могут запрещать встраивание отдельных роликов, требовать авторизацию или ограничивать видео по региону. Для приватного VK-видео используйте полную ссылку «Код для встраивания», содержащую `hash`. Приложение сохраняет этот параметр. Кнопки и реклама внутри самого VK-плеера контролируются VK; скрывать их через чужой iframe нельзя.

Для внешних плееров нужны доступ к vk.com / YouTube и разрешённые скрипты этих сервисов. Расширения, блокирующие VK API, мешают внешним кнопкам: приложение показывает понятное сообщение, а родные кнопки VK остаются доступны создателю.

## Проверки


Проверка ссылок выполняется локально. Браузерная проверка в этой среде прервалась; реальное воспроизведение VK не подтверждено. Доступность удалённых роликов зависит от сервисов и разрешений автора.
