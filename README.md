# REMEDIUM CINEMA

Онлайн-комната совместного просмотра: YouTube (при разрешённом встраивании) и прямые HTTPS MP4/WebM, синхронизация play/pause/seek, общий чат, приглашение по ссылке.

## Запуск
1. Установите Node.js 18+.
2. В папке проекта выполните `npm install`.
3. Выполните `npm start`.
4. Откройте http://localhost:3000.

## Чтобы смотреть с другого устройства
Разверните этот Node.js сервер на хостинге с поддержкой постоянного WebSocket/Socket.IO (например Render или Railway). После публикации откройте HTTPS-сайт, создайте комнату и нажмите «Пригласить». Простое размещение статического HTML на Netlify без серверной части не подходит.

## Ограничения
- YouTube: только видео, разрешающие embed; возможны ограничения по региону и авторизации.
- Rutube, VK, Netflix и другие сайты открываются внешними ссылками, но их видео здесь не синхронизируются.
- Прямые MP4/WebM должны быть доступны браузеру, поддерживать CORS/загрузку и кодеки устройства.
- Автовоспроизведение со звуком может требовать пользовательского действия на каждом устройстве.
- Комнаты и последние 100 сообщений на комнату хранятся в памяти процесса, не сохраняются при перезапуске.
- Для приватности комнаты используйте длинную случайную ссылку. Это не сквозное шифрование и не полноценная авторизация.
- Используйте только видео, которые имеете право просматривать.
